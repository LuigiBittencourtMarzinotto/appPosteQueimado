💡 Poste Queimado

Sistema web responsivo para registro de problemas de iluminação pública.

Sobre o projeto

O Poste Queimado é uma aplicação web desenvolvida para permitir o registro e acompanhamento de problemas relacionados à iluminação pública.

Objetivo

Facilitar o registro de postes com problemas de iluminação, permitindo o armazenamento das informações e o acompanhamento dos registros realizados pelos usuários.

Funcionalidades

📝 Registrar problema

Permite cadastrar problemas encontrados em postes de iluminação pública.

📋 Visualizar registros

Permite consultar os problemas registrados no sistema.

👨‍💼 Administração

Usuários administradores podem acompanhar e atualizar o status dos registros.

Tecnologias utilizadas

  • Laravel
  • PHP
  • MySQL
  • HTML
  • CSS
  • JavaScript
  • Docker
  • Git e GitHub
